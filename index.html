Font Viewer Studio

Privacy Policy

Effective date: November 20, 2026 · Developer: Kartinka Studio

1. About the application

Font Viewer Studio is a Windows desktop application for browsing, previewing, and comparing fonts. Its core functions operate locally and do not require registration or an internet connection.

2. Information accessed and processed

To display fonts, the application can enumerate files and folders in locations selected by the user and read supported TTF and OTF font files. File paths may contain personal information, such as a Windows account name.

The application also processes preferences (including enabled font sources and the last selected folder) and technical error information. Error logs may contain file paths, exception messages, and stack traces.

3. Local storage

For the Microsoft Store installation, settings and diagnostic logs are stored locally in the application's Windows LocalState storage. Temporary font preview files may be stored in TempState. These files are not automatically uploaded to the developer.

4. Network access and data sharing

Font Viewer Studio does not include built-in analytics, advertising trackers, or automatic transmission of font files, settings, or error logs to the developer. If you select a network folder, Windows may communicate with the relevant file server to access its contents.

5. Third-party components and platform services

The application uses software components for font processing and rendering, including HarfBuzz. No independent data transmission by these components was identified during source-code review. Windows and Microsoft Store may process diagnostic or operational data independently under Microsoft's own policies and your system settings.

6. Retention and deletion

Local preferences and diagnostic files remain on your device until removed through the application's or Windows' applicable data-management mechanisms. Temporary preview files may be deleted by the application or Windows. To request assistance locating or removing local data, contact the developer.

7. Support requests

If you contact the developer voluntarily, your email, message, and any files you choose to attach will be used to respond to your request and investigate the issue. Do not send sensitive personal information unless necessary. Support communications are not collected automatically by the application.

8. Children's privacy

Font Viewer Studio is a general-purpose font utility and does not intentionally collect personal information from children.

9. Changes to this policy

This policy may be updated when application functionality or applicable requirements change. The revised policy will be published at this address with an updated effective date.

Политика конфиденциальности

Дата вступления в силу: 20 ноября 2026 года · Разработчик: Kartinka Studio

1. О приложении

Font Viewer Studio — настольное приложение для Windows, предназначенное для просмотра, предварительного отображения и сравнения шрифтов. Основные функции работают локально и не требуют регистрации или подключения к интернету.

2. Доступ к информации и её обработка

Для отображения шрифтов приложение может получать список файлов и папок в выбранных пользователем расположениях и читать поддерживаемые файлы TTF и OTF. Пути к файлам могут содержать персональные сведения, например имя учётной записи Windows.

Приложение также обрабатывает настройки (включая активные источники шрифтов и последнюю выбранную папку) и технические сведения об ошибках. Журналы могут содержать пути к файлам, сообщения исключений и трассировки стека.

3. Локальное хранение

При установке через Microsoft Store настройки и диагностические журналы сохраняются локально в каталоге Windows LocalState приложения. Временные файлы предварительного просмотра шрифтов могут храниться в TempState. Эти данные не отправляются разработчику автоматически.

4. Сетевой доступ и передача данных

Font Viewer Studio не содержит встроенной аналитики, рекламных трекеров и механизмов автоматической передачи разработчику файлов шрифтов, настроек или журналов ошибок. При выборе сетевой папки Windows может обращаться к соответствующему файловому серверу для чтения её содержимого.

5. Сторонние компоненты и службы платформы

Приложение использует компоненты для обработки и отображения шрифтов, включая HarfBuzz. При анализе исходного кода не выявлена самостоятельная передача данных этими компонентами. Windows и Microsoft Store могут независимо обрабатывать диагностические и технические данные в соответствии с политиками Microsoft и настройками системы.

6. Хранение и удаление

Локальные настройки и журналы остаются на устройстве до удаления доступными средствами приложения или Windows. Временные файлы предварительного просмотра могут удаляться приложением или Windows. За помощью в поиске и удалении локальных данных можно обратиться к разработчику.

7. Обращения в поддержку

Если пользователь добровольно обращается к разработчику, его адрес электронной почты, текст обращения и приложенные им файлы используются для ответа и рассмотрения проблемы. Не следует отправлять чувствительные персональные сведения без необходимости. Приложение не собирает обращения в поддержку автоматически.

8. Конфиденциальность детей

Font Viewer Studio — универсальная утилита для работы со шрифтами; приложение не предназначено для целенаправленного сбора персональных данных детей.
